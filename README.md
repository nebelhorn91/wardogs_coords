# Wardogs Coordinate Calculator

A lightweight coordinate distance calculator for Wardogs.

Enter two positions using X/Y coordinates and the tool calculates the straight-line distance with the Pythagorean theorem:

```text
d = √((x₂ - x₁)² + (y₂ - y₁)²)
```

## Features

- Live distance calculation
- X/Y coordinate input
- ΔX and ΔY display
- Calculation steps
- Swap start and target positions
- Example coordinates
- Copy result button
- Responsive dark UI
- No framework or build step required
